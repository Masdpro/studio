# Closebuy phone app (Android and iPhone)

A native app built with React Native and Expo. It talks to the Closebuy server (`https://cbuyapp.com`)
through the same APIs as the website, so orders, bookings, wallets and accounts are shared.

Everyone uses one app:

- **Customers**: the Shop side (products, shops, markets, cart, checkout from the wallet, order tracking
  with the delivery code, errands) and the Book side (service businesses, photos of their work, booking a
  time, the end-of-job code, cancelling and changing the time). The Shop/Book switch flips the whole app.
- **Shops**: orders (accept, prepare, ready), products (photos, prices, Awoof deals, stock, pause),
  store details, earnings and withdrawals.
- **Service businesses**: bookings (accept, finish with the customer's code, no-show), services and
  portfolio photos, opening hours and days off, business details.
- **Riders**: available deliveries, collecting, entering the customer's code, sharing location with the
  customer while delivering, errand quotes.
- **Admins**: dashboard, verifications (documents and selfie photos), payouts, orders, bookings, users.
  Less common admin tools open the website.
- **Everyone**: sign-up (with the email code), verification documents and the live selfie, notifications,
  profile and password, and deleting the account (required by Apple and Google).

## Server it needs

The app signs in with `POST /api/mobile/session` and loads the home screens from `GET /api/mobile/catalog`.
Both are in this repo; **the live site must be deployed with them before the app can sign in.**

## Try it

- **Android phone**: open GitHub → Actions → *Phone app* → the latest run → download
  **closebuy-android-apk**, unzip, open `app-release.apk` on the phone (allow "Install unknown apps").
- **Local development** (needs Node 22):
  ```bash
  cd native
  npm install
  npx expo start            # then open it in a development build on your phone
  ```
  To use a local server instead of cbuyapp.com: `EXPO_PUBLIC_API_URL=http://<your-computer-ip>:3000 npx expo start`.
  The app uses camera, location and secure storage, so test on a phone with a development build
  (`npx expo run:android` or `npx expo run:ios`) rather than Expo Go.

## Publish on Google Play

1. Create a Google Play developer account (one-time US$25).
2. Create an upload key on your own computer (keep it and its passwords safe; never commit them):
   `keytool -genkey -v -keystore closebuy-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias closebuy`
3. Add GitHub repository secrets: `ANDROID_KEYSTORE_BASE64` (`base64 -w0 closebuy-upload.jks`),
   `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (`closebuy`), `ANDROID_KEY_PASSWORD`.
   The next run also produces **closebuy-android-play-bundle** (`app-release.aab`) to upload to Play.
4. Fill in the store listing, privacy policy (`https://cbuyapp.com/privacy`), Data safety form and content
   rating. New personal developer accounts must run a closed test (12 testers, 14 days) before going public.

## Publish on the App Store

1. Join the Apple Developer Program (US$99/year).
2. Build and upload with Expo's build service (`npx eas-cli build -p ios`, needs a free Expo account) or on a
   Mac (`npx expo run:ios --configuration Release`, then archive in Xcode).
3. In App Store Connect add the listing, screenshots, privacy policy and App Privacy answers, and give the
   reviewers demo accounts (customer and shop).

## Changing the app

- Name, bundle id (`com.cbuyapp.closebuy`; can't change after publishing), permissions text: `app.json`.
- Icon and splash: replace `public/logo-mark-orange.png` with a high-resolution logo and run
  `node scripts/make-app-icons.mjs` from the repo root.
- Screens are in `src/app` (one file per screen); shared pieces in `src/components` and `src/lib`.
- The `android/` and `ios/` folders are generated by `npx expo prebuild`; don't edit or commit them.
